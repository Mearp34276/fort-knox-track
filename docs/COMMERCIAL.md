# Commercial install / support / integration

**Owner:** M.E.

Open-source Fort Knox is free under MIT. Paid work is optional when you want hands-on help installing or integrating the track.

## What buyers get

| Offer | Typical range | You get |
|-------|---------------|---------|
| Install / setup help | **$150–$500** | Working local install, smoke-test `POST /v1/tolls` / `Track.report`, short handoff notes |
| Priority support | Quoted | Faster answers on tracks/trains, mock meter, treasury public-address wiring |
| Custom operator integration | Quoted | Scripting, agent hook, or product-side train reporting into the track |

Ranges are honest estimates, **not** income guarantees for the maintainer and **not** a fixed menu until scoped.

## How to buy

1. Open a GitHub Issue on this repo.
2. Choose the **Commercial quote** template (or add label **`commercial`**).
3. Fill in what you need, success criteria, and optional budget.
4. M.E. replies with a scoped quote. No payment until you agree.

Repo Issues: https://github.com/Mearp34276/fort-knox-track/issues/new/choose

## What this is not

- Not guaranteed income for anyone
- Not live fund movement by default (`LIVE_SEND` stays hard-off unless the operator enables it)
- Not a requirement for free MIT use
- Not money transmission licensing or counsel advice
